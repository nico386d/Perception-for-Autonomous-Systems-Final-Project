A complete stereo vision pipeline has been implemented for autonomous driving perception. The
system consists of three main components: first, stereo camera calibration and rectification to
correct lens distortion and align epipolar geometry; second, object detection and 3D tracking that
handles object identities through occlusion events using temporal consistency; and third, a machine
learning classifier trained to distinguish between pedestrians, cyclists, and cars. Moreover, this
pipline has to be robust enough to eliminate possible interferences that was also part of the raw
images given

All the 3D bounding box using dynamic scaling based on objects instead of using set templates
